# homepage

## 项目用途

Entropyorder 官方产品主页前端项目，包含页面源码、静态资源和构建配置。

## 仓库内容

当前默认分支为 `code-only`。主要入口和目录包括：

- `.github,.gitignore,README.md,index.html,package-lock.json,package.json,postcss.config.js,public,src,tailwind.config.js,vite.config.js`

## 使用建议

请先阅读仓库中的配置示例、`docs/`、测试文件和脚本注释，再根据实际环境运行。涉及模型、代理、对象存储或第三方服务的参数，请通过本地环境变量或未追踪的配置文件提供。

## 数据与安全

仓库只保存代码、文档和可复现的样例。不要提交真实凭据、个人信息、模型权重、原始数据或大体积运行产物；运行数据和缓存应放在仓库外。
